# 📖 Самоучитель: чтение Корана

**Приложение Шавката Ташходжаева для улучшения чтения Корана.**

Личное приложение для тренировки **беглого чтения** Корана. Произношение и таджвид — с устазом, здесь тренируем скорость и уверенность.

**Открыть:** https://shavkat2212-byte.github.io/quran-reading/
(на телефоне: меню браузера → «Добавить на главный экран» — будет как приложение)

## Как заниматься (10–15 минут в день)

Каждый урок — 3 круга:

1. **С подсказкой** — читаете вслух каждое слово; если не уверены, нажмите на слово и послушайте.
2. **Сам** — читаете всё ещё раз, уже не слушая.
3. **На время** — слова перемешиваются, нажимаете «Старт», читаете всё вслух, «Готово». Время сравнивается с **целью урока** и с вашим лучшим результатом.

Прогресс (пройденные уроки, серия дней 🔥, все попытки на время) хранится в памяти браузера телефона — без регистрации. Если очистить данные браузера или открыть с другого телефона, прогресс начнётся заново.

В приложении два раздела:

- **🔤 Буквы** (уроки L01–L17) — буквы группами похожих по форме, хамза и та марбута, все 28 букв, формы букв в начале/середине/конце слова, слоги с фатхой, касрой, даммой и вперемешку. Под каждой буквой — название по-русски (Алиф, Ба, Та…), в слогах — звук (ба, би, бу). Звука у букв пока нет: в открытых источниках не нашлось полного надёжного набора записей всех букв.
- **📖 Чтение: слова и аяты** (уроки 001–030).

Уроки чтения идут от простого к сложному: короткие слова → слова из 3 букв → сукун → шадда → артикль ال → танвин и долгие гласные → длинные слова → целые аяты → слова с сукуном и шаддой → знаки остановки (вакф) → целые суры (аль-Аср, аль-Фалак, ан-Нас, аль-Кафирун) → (уроки 016–030) танвин, мадд, длинный мадд ـٓ, хамза, та марбута, солнечные и лунные буквы, длинные слова 8–12 букв → суры джуза «Амма» целиком с остановкой в конце аята (ан-Наср, Курайш, аль-Филь, аль-Ма'ун, аль-Масад, аль-Кадр, ат-Такасур, аль-Кари'а, аш-Шарх, ад-Духа, ат-Тин, аз-Зальзаля) → аль-Мульк 1–5. В первых уроках 6–8 слов и щедрая цель по времени; дальше слов больше, а цель строже.

## Откуда текст и звук

Чтобы не было ни одной ошибки, слова **не набирались вручную**: текст (письмо усмани, как в мединском мусхафе), транскрипция и номер места в Коране взяты из [api.quran.com](https://api.quran.com) (v4).
Звук слов — `audio.qurancdn.com` (по-словное чтение quran.com), звук аятов — Мишари Рашид аль-Афаси с [everyayah.com](https://everyayah.com).

## 📖 Чтение Корана по страницам

Раздел на главной: одна страница мединского мусхафа (604 страницы) в день, начиная со 2-й страницы (сура аль-Бакара); аль-Фатиха (стр. 1) открывается отдельно.

- «Страница дня» — следующая после последней прочитанной. «Прочитал страницу ✓» отмечает её с датой (по желанию — со временем по секундомеру «⏱ Засечь»). После этого показывается «Завтра: страница N+1», но можно читать дальше, возвращаться и выбирать любую страницу («Выбрать страницу» — по номеру или по суре).
- По умолчанию — крупный сплошной текст. Галочка «Строки как в мусхафе» раскладывает слова по 15 строкам, как на странице мусхафа (по `line_number` из api.quran.com; шрифт тогда мельче — 14–20 px на телефоне). «Транскрипция» — латиница под каждым словом.
- Нажатие на слово — звук слова, на номер аята — весь аят (аль-Афаси), «▶ Слушать страницу» — все аяты подряд.
- Прогресс хранится там же, где и уроки (`localStorage`, ключ `pages`: `{"2": {"d": "2026-10-11", "ms": 185000}}`).

Все 604 страницы лежат в `pages/001.json … pages/604.json` (компактный формат, ~1–4 КБ), список сур — `pages/chapters.json`. Если файла страницы нет, приложение берёт её прямо из api.quran.com.
Пересобрать: `sh tools/fetch_pages.sh && python3 tools/build_pages.py` (формат описан в начале `tools/build_pages.py`).

## Как добавить новый урок

1. Создайте файл урока в формате ниже:
   - урок чтения — `lessons/016.json` (следующий номер);
   - урок букв — `lessons/letters/L18.json`.
2. Добавьте строку об уроке в `lessons/index.json` — в список `lessons` нужного раздела (`sections`).
3. Поднимите `VERSION` в начале `app.js` (и `?v=` в `index.html`), чтобы телефон точно получил обновление.
4. Закоммитьте в ветку `main` — через 1–2 минуты урок появится в приложении.

### Формат `lessons/index.json`

```json
{
  "title": "Самоучитель чтения Корана",
  "owner": "Шавкат Ташходжаев",
  "sections": [
    {"id": "letters", "title": "Буквы", "dir": "letters", "lessons": [
      {"id": "L01", "title": "Алиф, Ба, Та, Са", "subtitle": "ا ب ت ث", "level": 1, "count": 4, "targetSeconds": 15}
    ]},
    {"id": "reading", "title": "Чтение: слова и аяты", "dir": "", "lessons": [
      {"id": "001", "title": "Короткие слова из 2 букв", "subtitle": "Фатха, касра, дамма",
       "level": 1, "count": 6, "targetSeconds": 30}
    ]}
  ]
}
```

`dir` — папка внутри `lessons/`, где лежат файлы раздела (пусто — сама `lessons/`). Номера уроков (`id`) должны быть уникальны во всех разделах: у букв — `L01…`, у чтения — `001…`. Раздел «Буквы» показывается первым.

### Формат урока `lessons/NNN.json`

```json
{
  "id": "001",
  "title": "Короткие слова из 2 букв",
  "subtitle": "Фатха, касра, дамма",
  "level": 1,
  "targetSeconds": 30,
  "tip": "Подсказка к уроку (можно вставлять арабские буквы — покажутся коранским шрифтом)",
  "items": [
    {"type": "word", "ar": "هُوَ", "loc": "112:1:2",
     "audio": "https://audio.qurancdn.com/wbw/112_001_002.mp3", "translit": "huwa"},
    {"type": "ayah", "key": "112:1", "ar": "قُلْ هُوَ ٱللَّهُ أَحَدٌ",
     "audio": "https://everyayah.com/data/Alafasy_128kbps/112001.mp3",
     "words": [
       {"ar": "قُلْ", "loc": "112:1:1", "audio": "https://audio.qurancdn.com/wbw/112_001_001.mp3", "translit": "qul"}
     ]}
  ]
}
```

| Поле | Обяз. | Что это |
|---|---|---|
| `id` | да | номер урока, 3 цифры, совпадает с именем файла |
| `title`, `subtitle` | да / нет | название и короткое описание |
| `level` | нет | сложность: 1 — очень легко, 2 — легко, 3 — средне, 4 — сложнее, 5 — аяты |
| `targetSeconds` | нет | цель для 3-го круга (на время), в секундах, на весь урок. Если не указать — секундомер без цели |
| `tip` | нет | подсказка в жёлтой рамке |
| `items` | да | что читать. Рекомендуется 6–8 в лёгких уроках, 10–12 в сложных |
| `showHints` | нет | `true` — подсказки (`name`) показываются всегда в 1-м и 2-м круге (так сделано для букв) |
| `items[].type` | да | `word` — одно слово, `ayah` — целый аят, `letter` — буква или слог, `forms` — формы буквы |
| `items[].name` | для `letter`/`forms` | подсказка под буквой: название («Ба») или звук слога («ба») |
| `items[].forms` | для `forms` | формы буквы: отдельно, начало, середина, конец (с татвилем `ـ`, например `["ب","بـ","ـبـ","ـب"]`) |
| `items[].ar` | да | текст с огласовками (письмо усмани) — **копировать из api.quran.com, не набирать вручную** |
| `items[].loc` | для `word` | место в Коране: `сура:аят:слово` |
| `items[].key` | для `ayah` | `сура:аят` |
| `items[].audio` | для `word`/`ayah` | ссылка на mp3 (у букв нет) |
| `items[].translit` | нет | транскрипция латиницей (из api.quran.com), показывается по галочке |
| `items[].words` | для `ayah` | слова аята (те же поля, что у `word`) — нажимаются по отдельности |

**Ссылки на звук:**
- слово: `https://audio.qurancdn.com/wbw/SSS_AAA_WWW.mp3` (сура, аят, номер слова — по 3 цифры), например `wbw/001_002_001.mp3`. Номер слова берите из поля `position`, а **не** из `audio_url` API: в аятах со знаками остановки (ۖ ۚ ۜ ۞) `audio_url` сдвигается и ведёт на чужое слово;
- аят: `https://everyayah.com/data/Alafasy_128kbps/SSSAAA.mp3`, например `001002.mp3`.

**Где взять точный текст:**
`https://api.quran.com/api/v4/verses/by_chapter/112?words=true&word_fields=text_uthmani&per_page=50` — у каждого слова есть `text_uthmani` (текст), `audio_url` (звук) и `transliteration`.

Скрипты в `tools/`: `fetch.sh` скачивает данные api.quran.com в `raw/`, `build_letters.py` собирает уроки букв (каждая буква проверяется по имени Unicode), `build_lessons.py` — уроки чтения 001–015 и `lessons/index.json`, в конце он запускает `build_lessons2.py` — уроки 016–030 (слова подбираются правилами по огласовкам из текста api.quran.com: самые частые подходящие слова; в аятах — по-словные данные и звук). Запуск из корня репозитория: `sh tools/fetch.sh && python3 tools/build_letters.py && python3 tools/build_lessons.py`.

## 🌅 Утренние зикры

Раздел на главной («Утренние зикры») и по ссылке `#/adhkar`: 22 утренних зикра из книги «Крепость мусульманина» (Хисн аль-муслим, № 75–98), чтобы читать после утреннего намаза.

- У каждого зикра: арабский текст, транскрипция, перевод, сколько раз читать, достоинство и источник (Муслим 2723, аль-Бухари 6306, Абу Дауд 5074 и т.д.), кнопка «▶ Слушать» (запись с hisnmuslim.com).
- Счётчик: после каждого прочтения нажмите кнопку на карточке или большую кнопку внизу экрана — она всегда считает текущий зикр (удобно для 100 раз). Телефон коротко вибрирует; когда зикр закончен, карточка сворачивается и экран переходит к следующему. «↶ −1» отменяет лишнее нажатие. У «Ля иляха илля-Ллаху…» можно выбрать 10 или 100 раз.
- Общий прогресс вверху, «↺ Сбросить» — обнулить сегодняшние счётчики. Каждый новый день счётчики обнуляются сами; дни, когда прочитаны все зикры, дают серию 🔥.
- Откуда текст: арабский текст дуа взят из [asellam/HisnElMuslim](https://github.com/asellam/HisnElMuslim) и сверен по буквам со вторым набором [Seen-Arabic/Morning-And-Evening-Adhkar-DB](https://github.com/Seen-Arabic/Morning-And-Evening-Adhkar-DB) (совпадают полностью; три пропущенные огласовки исправлены). Аяты (аль-Курси, суры 112–114) — письмо усмани из api.quran.com, перевод Э. Кулиева. Сборка: `python3 tools/build_adhkar.py` → `adhkar/morning.json`.
- Прогресс: `localStorage`, ключ `qr.adhkar.v1`.

## 🌇 Вечерние зикры и 🕌 зикры после намаза

- `#/adhkar/evening` — 21 вечерний зикр (тот же счётчик; ключ `qr.adhkar.evening.v1`). Текст — глава «أذكار المساء» из asellam/HisnElMuslim, каждый сверен по буквам с Seen-Arabic. Для зикров, где вечером меняются слова («амсайна…»), записи нет — на hisnmuslim.com читается утренний вариант, поэтому кнопка «Слушать» у них скрыта.
- `#/adhkar/salah` — 12 зикров после обязательного намаза: истигфар ×3, «Аллахумма Анта-с-Салям», тахлили (Муслим 591–594, аль-Бухари 844), тасбих 33/33/33 + «ля иляха илля-Ллах…» (Муслим 597), аят аль-Курси, три суры, 10 раз после фаджра и магриба, дуа о полезном знании после фаджра. Счётчик сам обнуляется через час без нажатий (ключ `qr.adhkar.salah.v1`).
- На главной карточка зикров до 14:00 показывает утренние, после — вечерние; под ней кнопки «Утро / Вечер / После намаза».

## 🤲 Дуа

Раздел `#/dua`: 93 мольбы по темам — из Корана («Раббана…», 21 дуа), сон и пробуждение, дом, мечеть и азан, туалет и омовение, еда, одежда, поездка, трудность и грусть, долг, болезнь, покаяние и истихара, дождь/гром/новый месяц, общение. У каждой: арабский текст с огласовками, транскрипция, перевод, когда читать, источник, звук (hisnmuslim.com, для аятов — аль-Афаси). Поиск — по-русски, по транскрипции и по-арабски (без огласовок); ⭐ — избранное (`localStorage`, ключ `qr.dua.fav.v1`, ссылка `#/dua/fav`).

- Арабский текст не набирался вручную. Дуа из «Крепости мусульманина» — из asellam/HisnElMuslim; при сборке буквы каждого текста **обязаны** найтись во втором источнике — официальном API книги `hisnmuslim.com/api/ar/<глава>.json` (а также rn0x/Adhkar-json, rn0x/hisn_almuslim_json, Seen-Arabic), иначе сборка падает. Огласовки сравниваются по словам, явные опечатки исправлены списком `FIX`/`EXTRA` в скрипте.
- Аяты — api.quran.com (усмани, перевод Э. Кулиева — перевод всего аята), сверены по буквам с api.alquran.cloud.
- Транскрипция, перевод и источники — `tools/duas_spec.py`. Сборка: `python3 tools/build_duas.py` → `dua/duas.json`, `adhkar/evening.json`, `adhkar/salah.json`.
